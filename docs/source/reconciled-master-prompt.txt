CRITICAL SOURCE-OF-TRUTH RULE

The approved section images created for this project are the primary visual source of truth.

When this prompt conflicts with an approved section image, follow the approved section image.

Do not “correct” the approved imagery toward a different design philosophy. Recreate the visual language, hierarchy, composition, spacing, surface treatment, image presentation, and overall emotional effect demonstrated in those images.

The approved section images intentionally use:
- A luminous pearl-white and pale-cool-gray canvas
- Violet-to-blue accent treatments
- Select gradient-highlighted words
- Soft white elevated surfaces
- Rounded cards and image frames
- Subtle glass-like navigation and control surfaces
- Fine orbital lines and restrained glow
- Large product imagery
- Carefully composed interface callouts
- Alternating light and dark sections
- A premium futuristic consumer-AI tone

These are approved, intentional brand choices for Marketplace / AI.

Therefore, generic “never use purple,” “never use gradients,” “never use glassmorphism,” “never use rounded cards,” or “never center content” rules do not apply when they would conflict with the approved section imagery.

The rule is not “avoid every common AI visual device.” The rule is:
Use the approved devices with discipline, hierarchy, consistency, and excellent execution so the result feels authored rather than generated.

PROJECT

Project name:
Marketplace / AI

Product:
A premium web application that transforms ordinary seller photos into a complete, coordinated marketplace listing image campaign.

Primary customer:
Casual marketplace sellers, furniture and home-goods resellers, vehicle and equipment sellers, plant sellers, collectible sellers, and small resale businesses.

Core customer problem:
Marketplace listings are often held back by cluttered backgrounds, poor lighting, weak angles, inconsistent imagery, and incomplete visual coverage.

Primary promise:
Upload the photos you already have and receive a polished, coordinated image campaign designed to help the listing attract more attention, build buyer confidence, and present the item more effectively.

Primary conversion goal:
Upload listing photos.

Secondary conversion goal:
View transformations or example campaigns.

Customer flow:
1. Upload original photos.
2. Choose exactly 4, 6, 8, or 10 final images.
3. Pay.
4. Watch progress.
5. Receive the complete campaign in listing order.

The customer must never:
- Write prompts
- Choose individual shots
- Approve intermediate outputs
- Operate multiple tabs
- See raw JSON
- See model names
- See internal generation terminology
