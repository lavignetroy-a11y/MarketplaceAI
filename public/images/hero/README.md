# Hero section images

These files don't exist yet on purpose -- the hero renders a quiet placeholder ("Image coming
soon") until a matching file is dropped in. No code changes are needed later; just add files
with these exact names:

- `original.jpg` -- an ordinary, unedited seller photo (the "before").
- `main.jpg` -- the large, centered polished hero image (the "after").
- `alt-1.jpg` -- an alternate angle / campaign image (visible on all screen sizes).
- `alt-2.jpg` -- a second alternate angle / detail shot (desktop only).

All four should depict the same item, matching the campaign story the hero visual tells.
